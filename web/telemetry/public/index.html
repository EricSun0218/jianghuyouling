统计口径

“用户”按本地随机 ID 去重，是上报客户端数，不代表实名认证人数。AI 活跃要求至少一次成功调用。每次调用异步上报，失败不缓存、不补报，因此数字可能低于实际使用量。模型分类来自固定白名单，不上传自定义模型名。

Token 仅累计接口实际返回的用量；缺失不当成已知的 0，缓存输入和推理输出不重复相加。统计不接收对话、提示词、存档信息、Steam ID、API Key 或接口地址。
