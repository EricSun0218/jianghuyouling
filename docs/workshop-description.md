## 不只是 AI 对话，而是 AI 互动让江湖真的改变

《江湖有灵》不是给《太吾绘卷》加一个能聊天的窗口。

它的核心是:你和 NPC 说的话,会被 NPC 按照自己的性格、记忆、关系、随身物品、武学技艺、所在地与当前江湖局势去判断。说得动,TA 就真去做;做成了,结果会落到游戏里;做不成,也会据实拒绝。

赠物、传功、结义、疗伤、买卖、赴约、投奔、追杀、改换关系、共度春宵、散播秘闻、改变立场、过月江湖大事,都不只是台词。它们会尽量按游戏真实状态执行,并留下记忆与后果。

一句话概括:

**AI 不只是陪你聊天,而是在扮演一个能被你影响、也会影响江湖的人。**

## 自 0.27 起的更新（累计到 0.30）

0.27 之后没有再单独发工坊版本，中间几轮改进都攒到 0.30 一次放出。以下按你在游戏里能直接感受到的变化来说：

- 主动人物名单统一管理来信与过月行动：全部当前同道默认进入名单，聊过的普通人物也可在单聊顶部点“加入主动”；玩家能随时移除或重新加入。NPC 主动来信和过月主动行事都从该名单取人，但两项功能可在设置中分别关闭。同道会按长期记忆、显著关系、人设经历、近来对话和处境，在连续思考与行动中真的去做事——每做一步都会先看到真实结果，再决定继续、换办法或收手，而不是预先写死一整套计划。赠物、传功、疗伤、下毒、改关系等都能成为彼此承接的行动；某件事没办成，会看清原因再换可行做法。同道始终随太吾同行，不会在过月里擅自离队、赴约、迁居或独自远行；同地块普通江湖人可以承接各种当面行为，远方人物只能收到千里传音及承接言语能够成立的关系变化，赠物、偷窃、疗伤、授艺、杀伤绝不会隔空发生。杀人、擒拿、下毒只以精纯作为玩法硬门槛，仇怨、关系、记忆、人设、近期经历和处境都可能成为动机，不再额外压低概率或要求固定“强证据”；进入游戏本体战斗仍只在当面单聊出现。过月窗口会列清成败并收入纪事，真实行动也会并进该同道的聊天记录。
- 江湖事件真的会发生并逐月连载：事件人物会像聊天中的角色一样，自己选择合乎关系与前情的行动，查看人物、地点和持有物后再赠物、交易、偷窃、传授、写书、疗伤、赶路、改换关系、婚配、春宵、吐露秘闻、换装改容、改变正逆练，乃至下毒、擒拿和杀伤；看到每一步真实结果后再决定下一步，不受固定两三件事的限制，最后亲自收束成本回正文。成败都用绿字列清、失败写明原因。每桩大事逐月按真实人物、地点、恩怨往下推进，陌生 NPC 带门派身份、不写婴儿情节，你的参与会被写进去并可能牵动名望。全部可在“江湖见闻录”逐月回看，太吾可参与改写后续。
- 对话里可以直接开打：当面单聊时太吾或 NPC 都能提出切磋、相搏、生死斗；聊天先给确认按钮，确认时再次核对位置与存活状态，然后进入游戏本体战斗。远程、群聊、面对俘虏时不出现战斗入口。
- 群聊更耐用、记录不再“存满”：太吾每发一条消息，群内所有成员都会按各自人设与记忆回应，并可在设置中选择让他们彼此自动续聊一至三轮；这个轮数只管 NPC 自动交流，不限制你继续说多少句。群聊记录可无限增长，聊再久也不会“记录已满、保存失败”，更早的轮次自动分卷，回看/删除/导出照常覆盖全部历史。每人记忆按轮精确绑定，删轮、重试、清空、删群都真的清干净、不留残念，中途关游戏也会在下次续做清理。多人同时行动按顺序来、先避冲突，避免同一笔钱花两次或同一段关系被覆盖。注意普通群聊只是把几个人的对话摆在一起，不代表同处一地；同道行动者按游戏同行规则随太吾同行，其他目标是否在场仍以实际地块为准。
- 更顺手的输入与对话：主动名单中聊过的 NPC 会按设置频率主动联系太吾，新安装默认每次随机间隔 30–40 分钟；来信进入对应聊天和后续上下文，灵儿会用本地气泡提示，右侧“聊”和左侧人物显示未读状态。太吾点击赠物时，列表会直接排除当前装备。回车发送、群聊插话不变，新增 `Ctrl+Enter` 只换行不发送；新增 Windows“口述”语音输入（唤起系统 `Win+H`，识别文字只填输入框、由你确认、不自动发送，不录音不上传不额外花钱）；新增聊天导出（单聊/群聊/灵儿/全部导出为 Markdown，只含可见内容，不含系统提示、人设、世界书或密钥）；聊天框输入 `/帮助` 随时弹出功能速览。已经出现过的绿色行动结果也会随记录保存，关闭窗口再打开仍看得到，角色后续也记得这些真实结果。NPC 语音朗读继续保留。
- 人物画像更深、真实动作更稳：自动画像升级为固定八节、约 900~1800 字的“人物圣经”，先给可用底稿再后台补全、不卡对话。真实动作不会因网络抖动被重复执行；“做没做成”的确认丢了只就着同一件事补齐结果，绝不换名头把杀人、送礼、交易重来一遍，结果没弄清时 NPC 不会嘴上说“应该办成了”。改约赴约先撤旧约再立新约，商队好感按实际谈定值落地并能正常触发本体商队成就。
- 世界书与提示精简：完整默认世界书以叙事总纲常驻、百科章节按本轮输入、近期对话和当前人物有效人设关键词加载；修改后新老角色下一轮都读到最新设定。模型隐藏思考的表达提示词可在独立弹窗编辑；NPC 可见回复继续由原有世界书、人设、回复篇幅和太吾口吻设定控制。灵儿不代写、草拟、确认或保存世界书和任何人设，这两类内容仍由玩家在设置页亲自编辑或还原默认。
- 思考显示与运行开销：Gemini、DeepSeek 等模型的思考过程（含 `<think>` 一类标签）只显示在“思量”区，绝不混进 NPC 正文、聊天历史或导出文件。对话会按真实现场准备能力：商人、门派人物、千里传音和当面单聊各自得到完整适用范围；同一现场不会因为一句话没猜中意图而缺少本可使用的行动。具体快多少、省多少以你自己的模型和真实使用为准，不写未实测的数字。
- 旧存档数据迁移：从 0.27 及更早升上来的聊天、记忆、画像会按文件名里的太吾身份归到对应存档，各存档不再串档；旧原始文件永远原样保留供手工恢复；先开新档再回旧档不会认错。若你在新版清空过某本世界书，它会另存为一份“cleared”备份而非直接消失，既不会更新后自己冒出来又留着可找回。

## 你能改变什么

**情义关系**

结交挚友、义结金兰、拜师收徒、恋人、夫妻、归心入队、离队、绝交断义、和离分手、逐出师门、撮合姻缘、共度春宵。同性春宵也按游戏本体支持处理。

**馈赠传授**

赠银、赠物、赠资源、传功授艺、默写秘籍给太吾自研。NPC 也能把东西、功法、技艺给在场或被提及的第三方。

**以物换物**

任意两人可以当面以物换物。系统会先校验双方当前真实持有,双方都有才双向转移。物品、资源、银钱都可参与。

**恩怨杀伐**

挑拨结仇、化解旧怨、说动其杀人、绑架、下毒、放走俘虏。是否能成受精纯、毒药、绳子、身份关系等真实条件限制。

**救助与身体状态**

疗伤，查看自身伤势、气息（内息紊乱）与六类中毒，为另一名在场人物驱毒或调息，以及更衣换装。太吾当面提出梳妆并与角色说定后，可直接打开游戏本体“为NPC梳头修面”界面，由玩家选择装扮并使用本体执行逻辑，不经过好感等原互动前置限制；过月、月度江湖事件与 NPC 主动来信不会自行改变外貌。

**秘闻立场**

吐露秘闻、散播秘闻、改变对第三方观感、立场漂移、增添良性特性。

**行程目标**

前往某地、赴约、来寻太吾、营救、保护、投奔门派、追杀、迁居。不会只停在嘴上,会进入过月演算。

**商人买卖**

当面讨价还价,按真实货架与太吾银钱结算,买一件少一件。

## 对话不止一对一

- 当面可聊,远隔可用“千里传音”;俘虏也会按“就在眼前”处理。
- 可同时打开多个 NPC 对话标签,后台生成完成会标未读。
- 单聊里可“加人”组成群聊，多人共享同一段对话上下文接话；群聊本身不代表同地块。
- 你可在众人接话途中插话,他们会顺着新话题继续。
- NPC 有长期记忆:你说过的话、做过的事、TA 亲手落地的行为,后续会影响态度与反应。

## 过月江湖大事

过月会生成真实发生的江湖事件。每桩大事像连载故事:开篇定走向,之后逐月按真实人物、地点、恩怨、立场推进。事件详情会写明陌生 NPC 的门派身份,不出现婴儿情节;你的实际参与和选择会被写进去,也可能牵动名望。太吾可参与改写后续。

所有大事可在“江湖见闻录”逐月回看。纪事只整理江湖故事、行动结果、风闻和同道行止，不重复塞入单聊或群聊的逐字对话。

---

## 同道主动行事

过月对话升级成过月行为。全部当前同道默认进入主动人物名单，普通人物可在单聊顶部手动加入；若开启“过月主动行事”，系统会从当前名单稳定抽选设置数量，让他们根据长期记忆、显著关系、近来对话、人设和处境真实做事，而不是只传话。主动来信使用同一名单，但可单独关闭。

主动行为使用和聊天相同的多轮行动方式：看到真实结果、再决定下一步，直到同道自己收手并讲完本月经过。失败后会看清原因再换方案。近期反复出现的行为类型会动态降低优先级，较少出现的行为会相应提高；这不会调整人物抽选，同一人物仍可连续主动行事。读取回档时会按本体存档月份清理旧时间线的过月记录，使该月能够重新生成。同道不会离队、赴约、迁居或脱离太吾独自远行；同地块人物可承接当面行动，远方人物可收到千里传音；所有需要接触、交物或动手的行为都必须真实在场。结果都会写进本月动向详情,确实尝试过真实行动时才追加为该同道的一轮聊天记录。记忆不是每次强制写入,且只能记录已经确认的要紧转折。

## 灵儿助手

屏角常驻、可拖动的小助手。她现在内置新的古风默认头像，玩家自定义图片仍会优先显示。她能按你问的内容调出对应的功能说明、NPC 行为、过月玩法、记忆与设定、群聊记录、模型语音或排障知识，讲解本 Mod、修改除世界书/人设外的常用设置、查太吾绘卷见闻百科、给配置建议、代笔拟太吾要说的话，也能直接分析 Player.log 排查常见报错。世界书与任何人设只由玩家在设置页亲自编辑，灵儿不会代写、草拟或保存；她的名字、人设、形象图片仍可由玩家自定义。

## 自定义

世界书内置完整太吾世界观，支持分类、优先级、常驻/关键词触发、导入导出与高级纯文本。世界书和人设设置页会直接显示当前生效文本，保存即保存完整自定义，只保留“还原默认”。世界书可编辑到 500000 字，NPC 与助手人设可编辑到 250000 字。NPC 人设、助手人设、太吾口吻、难度、回复篇幅、江湖事件文风、后台模型、思考显示和流式输出都在游戏内“设置”里调；模型隐藏思考的表达提示词可在“对话”页单独弹窗编辑，可见回复仍沿用原有世界书格式。

数据全存本地。正常更新 Mod 不会主动删除你的世界书、人设、记忆和聊天记录。

## 使用前必读

本 Mod 不内置模型,需要你自备 OpenAI 兼容、支持工具调用(function calling / tool calling)的大模型接口。

**推荐优先使用 DeepSeek。** 本 Mod 对 DeepSeek 的工具调用、多轮行动、思考协议、流式输出和缓存进行了持续真实 Key 回归；游戏内默认已填好官方接口以及主模型 deepseek-v4-pro、后台模型 deepseek-v4-flash，新用户通常只需申请并填写 DeepSeek API Key。

Claude / GPT / Gemini / 通义 / Kimi / MiniMax 等兼容模型及本地模型仍可使用。千问新开源 Qwen3.8 可直接连接本机 Ollama，Mod 会自动适配原生聊天、思考、流式输出和多轮工具调用。游戏内“设置”填写 baseUrl、model、apiKey。联网生成和接口费用由你自己的账户承担,Key 只保存在本地。
