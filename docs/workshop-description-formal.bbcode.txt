[h1]江湖有灵[/h1]

【当前版本】0.34.0.27

[b]AI 对话，不止会聊天。NPC 会记住、会选择、会行动，也会让整个江湖因此改变。[/b]

让 NPC 拥有长期记忆并真实行动，你说的话会改变江湖。

[b]0.34.0.27：修复人设增量格式误拒与受限行动预检。[/b]

人设增量直接接收新增正文，由程序整理格式；唯一一次纠正携带具体失败原因，仍失败则保留原画像与记录。统一过月受限行动预检，补全监狱位置查询，修复行动结果缺字并完善失败诊断。不改写玩家原设，不传送人物；长期“未知之地”问题仍需存档定位。

[h1]NPC 真正能做什么？[/h1]

[list]
[*][b]情义与身份[/b]：结交、结义、拜师、收徒、爱恋、成婚、归心入队、离队、绝交、和离、逐出师门、撮合姻缘。
[*][b]财物与交易[/b]：赠送银钱、物品与资源，以物换物，和商人买卖、议价，查看并购买真实货架上的商品。
[*][b]武学与传承[/b]：传功授艺，把已经掌握的功法写成秘籍赠人，调整功法正逆练方向。
[*][b]行程与生活[/b]：相约见面、主动来寻、投奔、营救、保护、追杀、迁居、疗伤、查看自身伤势/气息/中毒、为他人驱毒或调息、换装；当面说定后可进入本体“梳头修面”界面，由玩家选择装扮。
[*][b]恩怨与江湖手段[/b]：结仇、和解、偷窃、下毒、擒拿、绑架、释放俘虏、亲密相伴，以及因性格和欲望引发的激烈冲突。
[*][b]原生战斗[/b]：太吾或 NPC 都能在对话中提出切磋、相搏与生死斗，确认后直接进入游戏本体战斗。
[/list]

行动会真实改变关系、财物、伤势、行程、身份与恩怨；失败后角色也会根据原因调整下一步。

[img]https://images.steamusercontent.com/ugc/14806165065684027178/B16A840687F8CDA847B590B88FBFF4D7178C3901/[/img]

[h1]灵儿：真正陪你闯江湖的助手[/h1]

灵儿常驻屏角，可讲解功能、查阅见闻、提供建议、润色发言、分析并导出日志；她拥有独立记忆，名字、人设和头像均可自定义。

[img]https://images.steamusercontent.com/ugc/14615471276795860949/8BB91F41451B42BB5ECDB28476C02B189F5DFE9C/[/img]

[h1]每个人，都带着自己的过去[/h1]

NPC 会记住谈话、经历、承诺与行动，并结合地点、时间、关系和人物画像作答；群聊经历也会延续到之后的单独交谈。

已聊过的人去世后资料会保留，可主动与灵魂交谈；灵魂不主动来信、不参与过月或行动。

[img]https://images.steamusercontent.com/ugc/16298926871924720078/AF8978C403463FD9AAD3D6537CB514B58690C0C7/[/img]

[h1]一席群聊，众人能一起说、一起做[/h1]

你可以邀请多人同席，每个人保留自己的性格、关系和记忆，并能彼此接话、商议及真实行动；群聊和行动结果都会完整保存。

[img]https://images.steamusercontent.com/ugc/17055599751030854897/D138106E9AE8EE618D326B8C2CC7D6F49B033A0E/[/img]

[h1]同道不再只是跟随，而会主动生活[/h1]

过月时，同道会结合性格、心之所系、记忆、关系与处境自主行动；不同人物各有倾向，但不受死板选项限制。

他们可以拜访、赠礼、交易、传授、疗伤、调查秘闻、改变关系和处理恩怨；失败后会看懂原因并继续思考。

[img]https://images.steamusercontent.com/ugc/10303280312160479415/4E383A0FB13692EE1160E4AC4DA7EE62D5BE88D0/[/img]

[h1]每个月，都可能诞生一段江湖连载[/h1]

江湖事件由真实人物调查、交涉和行动后写成连续武侠故事；未了的恩怨、秘密与关系会延续到下月。

[b]太吾可以参与并改变事件后续与自身名望。[/b] 事件和同道行动并行生成，完成一项便先显示，其余可在“过月纪事”回看。

[img]https://images.steamusercontent.com/ugc/10855864778783750672/ACCD17CFC1851687F415B904386965BEA9B27C01/[/img]

[h1]为长期游玩打磨的聊天体验[/h1]

[list]
[*]单聊、群聊、灵儿与过月内容可以同时生成，多页签互不阻塞。
[*]主动人物名单同时约束 NPC 主动来信与过月主动行事，两项功能可分别关闭；全部当前同道默认在名单中，聊过的普通人物可在单聊顶部点“加入主动”。新安装的主动来信默认每次随机间隔 30–40 分钟。
[*]太吾点击赠物时，列表不会显示当前装备，避免误送正在使用的物品。
[*]支持千里传音、未读提醒、重试、删除、清空与完整聊天记录导出。
[*]回车发送，Ctrl+Enter 换行；多行输入框会随内容自然增高，并支持 Windows 口述输入与 NPC 语音朗读。
[*]模型的思量与正文分开显示，不会混进角色回答、历史记录或导出文件。
[*]回复、工具行动与记忆整理经过专项提速，长对话和多人群聊也会尽量保持顺畅。
[/list]

[h1]把这个江湖写成你想要的样子[/h1]

内置太吾世界背景，并支持编辑世界书、NPC 人设、灵儿人设和太吾口吻。自定义 NPC 人设原文不会被 AI 改写，长期经历会单独追加；百科按对话与人物命中，世界书更新对新旧角色生效，特殊角色可使用专属人设。

“省钱、均衡、最佳体验”三档可一键调整过月、灵儿、群聊与同道人数等主要设置，也可继续逐项微调。

[h1]开始前只需要[/h1]

本 Mod 不内置大模型，需要自行准备支持工具调用的兼容接口。

[b]推荐优先使用 DeepSeek。[/b] 默认已填官方接口、主模型 deepseek-v4-pro 和后台模型 deepseek-v4-flash，通常只需填写 API Key；工具调用、思考、流式输出和缓存均经过真实 Key 回归。

Claude、GPT、Gemini、通义、Kimi、MiniMax 及本地模型仍可用。本机 Ollama 的千问新开源 Qwen3.8 会自动适配原生思考、流式输出和多轮工具。接口费用由玩家账户承担；密钥和游戏数据均保存在本机。
