1. event_secret 在人物因信任、报恩、警告、求援、交换情报、拉拢、试探、挑拨、威胁、报复、证明身份或推动计划而决定吐露时选择。秘闻必须推动当前因果，不能为了凑“传递”类别随便泄密。
2. 先确定 a（讲述者）与 b（接收者）。若本轮已有针对 b 的权威秘闻候选和原始 index，可直接 event_secret；否则用 event_query_person(person=a,section=secrets,secret_target=b) 选择。代码会自动补做接收者资格预检，但不能替模型猜未知 index。
3. 普通 secrets 查询只证明讲述者知道，不能证明 b 尚未知情。无候选时换接收者、换另一桩秘闻或换行为；预检拒绝表示没有传播，不记作故事失败。
4. 同一回不向同一人重复传播同一秘密，也不改写成模型虚构内容；成功后正文必须明确说出权威秘闻，而不是只写“告诉了一个秘密”。
