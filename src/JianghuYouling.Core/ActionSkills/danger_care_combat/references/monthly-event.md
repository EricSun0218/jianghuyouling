2. event_heal 在争斗后的救命、报恩、赎罪、交换条件、保护弱者、维系关系或医者职责自然承接前情时选择。刚正、仁善、重情人物看到可救者时倾向更强；目标没有可处理伤势时改为其它照料或关系后果，不能硬凑疗伤。
3. event_capture 在需要审问、控制、押解、阻止继续作恶、救回人质、交差、逼迫交换、扣作筹码、强行带走或避免杀人时选择。刚正者可因惩戒和制止恶行擒拿；唯我、叛逆或冷酷者也可因利益、嫉妒、占有和胁迫掳走。
4. event_poison 在人物想暗中削弱、报复、灭口、控制、制造混乱、阻止追击或避免正面对抗时选择。毒型要服务具体目的：烈毒偏直接伤害，郁毒偏压抑耗损，寒毒偏迟滞虚弱，赤毒偏躁烈内伤，腐毒偏持续侵蚀，幻毒偏迷乱控制。

8. 自动预检发现确定不可能时不派发，也不写成故事失败；真实派发后的明确失败才进入余波，并依据失败原因改变目标、手段或后续因果，不能原样重试。
