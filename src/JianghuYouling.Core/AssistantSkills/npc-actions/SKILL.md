# NPC 行为

NPC 只有取得权威成功回执后才能把行动说成已经发生；明确失败要承认失败并按原因继续思考，回执终态未知则停止同一副作用，避免重复扣物或重复改变状态。

对话可促成的主要行为：结交挚友、义结金兰、拜师收徒、认义父义母或收义子义女、恋人夫妻、归心入队或离队、解除关系、说媒；明确自愿建立义亲时不硬卡年龄、双向好感或已有在世父母子女，只保留本体关系互斥与重复关系安全校验。恋人夫妻或对太吾情意深厚的成年人可共度春宵，同性同样支持，是否有孕由本体判定。<!-- JHYL_ASSISTANT_KB_SPEND_NIGHT_SAME_SEX -->

物品与传承：赠银赠物、任意两名角色以物换物、NPC 偷取第三方物品、把真正会的武学或技艺回忆成书赠人、当面亲授第三方、太吾把所学写成书赠 NPC、太吾当面教授 NPC。买卖、交易和议价不只限于银钱；钱不够、舍不得收钱或双方各有所求时，NPC 可主动查询双方持物并改用以物换物，不必等玩家逐字提出。交换前实时核验双方持有物和数量，任一边不足整笔不落地。当前对话 NPC 的真名可直接解析为本人。<!-- JHYL_ASSISTANT_KB_BARTER_ANY_TWO JHYL_ASSISTANT_KB_BARTER_STREAM_DIAG JHYL_ASSISTANT_KB_CURRENT_NPC_NAME_ALIAS -->

武学传给太吾时采用回忆成书，让太吾自行研习；太吾教授 NPC 前会重新读取太吾当前所学，技能类行动也会在使用前刷新，不能拿旧缓存误报不会。<!-- JHYL_ASSISTANT_KB_TAIWU_TEACH_REFRESH JHYL_ASSISTANT_KB_SKILL_REFRESH_BEFORE_TOOLS -->

恩怨与危险行为包括结仇化怨、下毒、绑架、杀伤和释放俘虏；必须满足人物、地点、毒药、绳索、精纯等真实前置。玩家不能仅凭一句话直接从 NPC 身上偷窃；偷窃是 NPC 自主或受托针对第三方的行为。偷窃败露或其他动作失败也必须继续给出自然正文。

还支持疗伤、改变好感与立场、增添良性特性、自主换装、调整已学功法正逆练、吐露或传播确知秘闻、查询人物正在运转和装配的功法与装备、门派中人为太吾说项，以及赴约、来寻太吾、营救、护卫、投奔、追杀、迁居等逐月行程。玩家在当面单聊中提出梳妆后，可进入游戏本体“为NPC梳头修面”互动；过月、江湖事件与 NPC 主动来信不会自行改变外貌。查询“会哪些功法”不同于查询“当前正在运行/装配什么”。<!-- JHYL_ASSISTANT_KB_NPC_BUILD_QUERY -->

商人当面可按原生角色商店或同地行商的真实货架与银钱买卖议价；首次查看会像打开本体商店一样建立或刷新货架，货架库存与 NPC 随身背包严格区分。群聊中的 NPC 也能在位置与前置允许时一起通过对话行动；战斗入口只在当面单聊提供，并由太吾确认后进入本体战斗。
