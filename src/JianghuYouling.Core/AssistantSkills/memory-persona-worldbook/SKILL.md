# 记忆、人设与世界书

每名 NPC 每轮回复前都会搜索一次自己的长期记忆，记忆较多时按当前话题相关性精选，不会把全部记忆无差别塞进上下文；Agent 仍可围绕更窄主题再次回想。成功提交对话后才巩固召回和异步整理，记忆整理不阻塞当轮回复。

系统使用八节详细自动画像；画像会根据单聊、群聊和长期记忆逐步更新，只固化稳定性格、价值观、关系与人生变化，不把当前地点、临时心情、一时伤病和短期资源写成永久锚点。玩家手写的自定义人设是最高权威，原文不会被机器覆盖；原文会参与画像失效判定与重新蒸馏，自动画像在其下继续吸收后来形成的稳定经历和关系变化。`replace` 只替换内置特殊人设，`append` 同时保留内置特殊人设，两种模式都自动演化。<!-- JHYL_ASSISTANT_KB_PERSONA_WORLD_BOOK_MODES -->

世界书提供默认《太吾绘卷》世界观。设置页的“条目管理”可按分类整理条目、逐条启用或停用，并选择常驻或关键词触发；分类本身不发送给模型。高级纯文本继续兼容 `@关键词,关键词2:内容`、`@@关键词` 多行块和 `!内容` 临场铁令。每轮对话都会重新读取当前一致快照；玩家修改后，旧角色和新角色下一轮都使用新世界书，旧画像或梗概中冲突背景按内容指纹失效。世界书只管背景与规则，不能关闭行动能力；改变游戏状态仍必须真实行动并取得回执。<!-- JHYL_ASSISTANT_KB_WORLD_BOOK_TOOL_GUARD -->

世界书可编辑到 500000 字，NPC 与灵儿人设可编辑到 250000 字；保存不会静默截断，超出当前模型上下文时会明确提示。NPC 对话不再另设一份重复的整篇文风正文；世界书条目、人设、回复篇幅和太吾口吻继续控制背景与可见回复格式，模型隐藏思考的表达提示词可在“对话”页的独立弹窗中编辑。覆盖世界书前保留 `.bak`，并采用 main/tmp/bak 原子恢复，避免写盘中断破坏正文。<!-- JHYL_ASSISTANT_KB_WORLDBOOK_SAFE_SAVE -->

你没有代写、草拟、确认或保存它们的工具。玩家要求灵儿修改世界书、NPC 人设或灵儿自己的人设时，只能说明设置页位置、格式、关键词词条和铁令语法，请玩家亲自编辑或还原默认；不能生成一份可直接当作完整世界书/人设保存的正文，也不能声称已经修改。<!-- JHYL_ASSISTANT_KB_NO_PERSONA_WORLDBOOK_AUTHORING -->
