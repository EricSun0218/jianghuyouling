# 功能总览

<!-- JHYL_ASSISTANT_KB_SYNC -->
<!-- JHYL_ASSISTANT_KB_VERSION:mod=0.34.0.40,taiwu=1.1.21,buildid=25596993 -->

当前版本为 0.34.0.40，适配《太吾绘卷》1.1.21 / Steam build 25596993。测试版与正式版使用同一功能版本。

最近更新（0.34.0.40）：过月未完成任务不跨月或重启后续跑，文字记录保存失败不会卡住下一月份。移动等中断在主动行事人物卡显示具体原因并保留已确认行动；江湖事件请求失败单独显示错误原因，兜底见闻不掩盖失败。已执行动作不回滚，未知动作不盲目重试，详情正文仍按需生成。配置及存档不变，旧中断记录不会自动补写，更新后请重启游戏。

此前 0.34.0.38：修复已有聊天记录时思量被关闭的问题。旧回复作为明确标注发言人的历史资料传入，不再因缺少历史思考而关闭新一轮思考；当前工具链仍完整回传真实思考。同步修复江湖事件初始资料误触发关闭思考。

此前 0.34.0.37：修复同道主动行事和过月江湖事件在压缩旧工具上下文后出现 reasoning_content HTTP 400。压缩摘要明确作为历史数据，真实模型回复完整回传原始思考；无工具回复后继续行动也保留思考。正确识别 deepseek-flash。

此前 0.34.0.36：灵儿新增清剿外道巢穴委托，每单接单后成功清除任意一处，按首次完成巢穴的实际难度由低到高对应九品至一品，发放3至4项奖励。普通胜场、失败退出、义士据点和剑冢不计入。杀人目标只选太吾活着的仇人，不要求聊过天；发出后和解仍保留。已有委托不自动删除，发布频率和NPC委托规则不变。

此前 0.34.0.35：NPC 单聊和千里传音可点击“写书赠送”右侧的“总结对话”，合并旧梗概和全部未压缩内容；没有新内容时不发请求，处理中可中断。手动总结和自动压缩后，逐字原文继续显示在当前聊天窗口，重开仍能回看和完整导出。累计梗概显示在旧原文之后、新消息之前；手动总结完成后，在聊天底部显示“对话总结 · 累计梗概”。群聊和灵儿暂不提供手动总结入口。

此前 0.34.0.34：模型配置改为可滚动下拉列表，选中后点击“立即切换”应用，原有加密保存、删除与测试流程不变。默认开启独立 AI 使用计数，每次调用异步上传日期、随机客户端/去重 ID、固定模型分类、成功状态及接口返回的输入/输出 Token。不上传聊天、提示词、存档、Steam ID、密钥、接口地址或自定义模型名；仅在本地保存随机客户端 ID，不保存统计缓存、失败不补报，不影响游戏。

此前 0.34.0.33：修复新手教程中与义父等剧情人物聊天或打开互动记录时后端崩溃的问题：教程世界没有预生成护卫数据，人物副本现在只在正式江湖世界建立，教程与游戏内指引世界会如实提示“请在教程结束、进入正式江湖后再试”。此前 0.34.0.32 修复历史人物映射误拦已确认副本的问题。当前存档确认副本归属且与本地登记一致时，不再因其他失效历史来源而挡住聊天开窗、发送准备和缓存立绘读取。不改复制规则，不按姓名或模板合并人物，不清理旧登记、聊天、记忆或立绘资料；资料迁移继续严格核验来源。此前升级读取旧版本登记、过月等待本体存档完成、风闻恢复与旧请求回包隔离继续保留。人物详情卡死仍需游戏内复测。长期显示“未知之地”的人物问题仍需存档定位，不宣称已经修复。

向玩家介绍时先讲效果，不讲工具英文名、内部协议或代码。第一大功能是 NPC 不止会聊天，还会记住、选择并以真实游戏行动改变江湖；第二大功能是灵儿虚拟助手与太吾专属“系统”，她会主动弹消息、记住玩家、介绍与引导全部功能、查询百科、分析日志、一键把诊断日志导出到桌面，并修改获准设置。灵儿默认每60分钟用纯代码发布系统任务，可设高频30分钟、低频90分钟或关闭；新任务复用灵儿气泡通知，允许多项同时进行且不调用模型。普通任务品级概率随本体世界进度变化，各品级始终有机会；击杀任务只从太吾活着的仇人中选择目标并按其精纯定级，不要求聊过天，发出后和解仍保留。清剿任务要求接单后成功清除任意一处外道巢穴，按首次完成巢穴的实际难度由低到高对应九品至一品；普通胜场、失败退出、义士据点和剑冢不算完成。全部进行中任务只作为她每轮可见的上下文、不写入长期记忆，并能指导玩家完成；普通任务固定发放2项组合奖励，击杀与清剿外道巢穴任务发放更丰厚的3至4项组合奖励，可包含物品、资源、银钱和威望。其余功能包括 NPC 自主委托、右侧委托簿、代笔自学习、NPC 单聊、千里传音、多人群聊与随时插话、同地点多人协同行动、当面单聊发起原生战斗、聊天记录与行动结果导出、按当前人物聊天和记忆“往事成书”、详细动态人物画像、可导入导出江湖有灵专用 JSON 的世界书、语音输入与朗读、多页签并行聊天、过月同道主动行事和过月 AI 江湖事件。

人物页可打开 AI 对话或千里传音，也可点“往事成书”，只用太吾与当前人物的单聊、此人参与的群聊和此人的长期记忆写成小说；写作要求可配置，默认是金庸式武侠气质，成稿可以导出。普通单聊顶部也有同名入口，并可加入或移除主动人物名单、查看人物详情、编辑或更新人设、加人组群、导出记录、清空记录和打开设置。主动名单同时用于主动来信与过月主动行事，但两项功能可在设置中分别关闭。输入框上方另有太吾主动赠物、传授、写书赠送入口；赠物选择窗不会显示太吾当前装备，其他选择窗支持按分类、品级、门派筛选与多选，也可附带一段要同时说的话，行动结果和这段话会作为同一轮发送。“写书赠送”右边的“总结对话”用于 NPC 单聊（含千里传音），与自动压缩共用流程：将旧梗概和上次压缩后至点击时的全部未压缩内容合为累计梗概，并在保存成功后显示于聊天记录；逐字原文仍保存在归档中，可完整导出。总结会调用模型，可点“中断”取消；没有新内容时不发请求。群聊和灵儿暂不提供此入口。灵儿页同一位置提供诊断日志导出与完整 Mod 介绍。聊天输入框 Enter 发送，Ctrl+Enter 换行。聊天框输入 /帮助（或 /help、单个 /）会本地显示功能速览，不发模型请求也不进入聊天记录。<!-- JHYL_ASSISTANT_KB_CHAT_HELP_COMMAND -->

总结或自动压缩只缩短模型的逐字上下文，累计梗概和已归档原文都会继续显示在当前聊天窗口，关闭再打开也能回看；不会因为总结而隐藏旧消息，也不需要独立的聊天记录页面。最新累计梗概显示在已压缩原文之后、未压缩新消息之前；手动总结完全部现有消息后，结果会显示在聊天底部，标题为“对话总结 · 累计梗概”。已归档轮次可阅读、查看原有图片和朗读，不再提供仅适用于未压缩轮次的删除、重试和生图写回。

群聊只表示共享一段多人对话，不自动证明所有人处于同一地点；当面行为始终按游戏中的实时位置判定。关闭聊天窗或切换页签不会丢失对话，真实行动结果会随聊天历史回放，导出 Markdown 时也会保留。纪事只展示江湖事件和同道行止，不混入普通对话记录。

灵儿不是江湖 NPC，而是能主动弹消息的虚拟助手 Agent；主动气泡只写一两句自然完整的话，不截成半句。她可以介绍功能、查询百科、分析本地日志并按玩家本轮明确指令修改允许的 Mod 设置，但不能替玩家编写或修改世界书和任何人设。<!-- JHYL_ASSISTANT_KB_PROACTIVE_SHORT -->
