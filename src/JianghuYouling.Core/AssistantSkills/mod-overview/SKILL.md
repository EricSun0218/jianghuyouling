# 功能总览

<!-- JHYL_ASSISTANT_KB_SYNC -->
<!-- JHYL_ASSISTANT_KB_VERSION:mod=0.34.0.27,taiwu=1.1.21,buildid=25596993 -->

当前版本为 0.34.0.27，适配《太吾绘卷》1.1.21 / Steam build 25596993。测试版与正式版使用同一功能版本。

最近更新（0.34.0.27）：自定义人设增量直接接收新增正文，由程序整理格式；唯一一次纠正携带具体失败原因，仍失败时保留原画像与未吸收记录。玩家原设保护、长度及长期证据检查继续保留。统一过月同道与江湖事件的受限行动预检，补全已登记监狱内人物的位置查询，修复行动结果缺字并补充失败诊断。不传送人物或清除本体状态；长期显示“未知之地”的人物问题仍需存档定位，不宣称已经修复。此前的通知异常隔离、实时魅力上下文和复制人回档保留规则不变。

向玩家介绍时先讲效果，不讲工具英文名、内部协议或代码。第一大功能是 NPC 不止会聊天，还会记住、选择并以真实游戏行动改变江湖；第二大功能是灵儿虚拟助手与太吾专属“系统”，她会主动弹消息、记住玩家、介绍与引导全部功能、查询百科、分析日志、一键把诊断日志导出到桌面，并修改获准设置。灵儿默认每60分钟用纯代码发布系统任务，可设高频30分钟、低频90分钟或关闭；新任务复用灵儿气泡通知，允许多项同时进行且不调用模型。普通任务品级概率随本体世界进度变化，各品级始终有机会；击杀任务从太吾聊过的人中选择目标并按其精纯定级。全部进行中任务只作为她每轮可见的上下文、不写入长期记忆，并能指导玩家完成；普通任务固定发放2项组合奖励，击杀任务固定发放更丰厚的3至4项组合奖励，可包含物品、资源、银钱和威望。其余功能包括 NPC 自主委托、右侧委托簿、代笔自学习、NPC 单聊、千里传音、多人群聊与随时插话、同地点多人协同行动、当面单聊发起原生战斗、聊天记录与行动结果导出、按当前人物聊天和记忆“往事成书”、详细动态人物画像、可导入导出江湖有灵专用 JSON 的世界书、语音输入与朗读、多页签并行聊天、过月同道主动行事和过月 AI 江湖事件。

人物页可打开 AI 对话或千里传音，也可点“往事成书”，只用太吾与当前人物的单聊、此人参与的群聊和此人的长期记忆写成小说；写作要求可配置，默认是金庸式武侠气质，成稿可以导出。普通单聊顶部也有同名入口，并可加入或移除主动人物名单、查看人物详情、编辑或更新人设、加人组群、导出记录、清空记录和打开设置。主动名单同时用于主动来信与过月主动行事，但两项功能可在设置中分别关闭。输入框上方另有太吾主动赠物、传授、写书赠送入口；赠物选择窗不会显示太吾当前装备，其他选择窗支持按分类、品级、门派筛选与多选，也可附带一段要同时说的话，行动结果和这段话会作为同一轮发送。灵儿页同一位置提供诊断日志导出与完整 Mod 介绍。聊天输入框 Enter 发送，Ctrl+Enter 换行。聊天框输入 /帮助（或 /help、单个 /）会本地显示功能速览，不发模型请求也不进入聊天记录。<!-- JHYL_ASSISTANT_KB_CHAT_HELP_COMMAND -->

群聊只表示共享一段多人对话，不自动证明所有人处于同一地点；当面行为始终按游戏中的实时位置判定。关闭聊天窗或切换页签不会丢失对话，真实行动结果会随聊天历史回放，导出 Markdown 时也会保留。纪事只展示江湖事件和同道行止，不混入普通对话记录。

灵儿不是江湖 NPC，而是能主动弹消息的虚拟助手 Agent；主动气泡只写一两句自然完整的话，不截成半句。她可以介绍功能、查询百科、分析本地日志并按玩家本轮明确指令修改允许的 Mod 设置，但不能替玩家编写或修改世界书和任何人设。<!-- JHYL_ASSISTANT_KB_PROACTIVE_SHORT -->
