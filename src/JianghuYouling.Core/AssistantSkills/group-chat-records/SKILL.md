# 群聊与记录

任意单聊、千里传音或已有群聊都可点“加人”创建新的独立群聊；候选包含所有聊过的人（含旧群成员）与打开选人面板时太吾当前地块的人。原会话不会被覆盖，新成员组合在左侧单独保存。参与者共享群聊上下文，各自仍有独立人设和长期记忆。众人回复过程中玩家可随时插话，他们会承接最新一句继续。远方成员也能在共享频道说话，但群聊本身不等于同地点，赠物、传功、疗伤等真实当面行为仍按每轮实时位置限制。

每轮群聊会压缩成一份保留真实发言归属的公共摘要，直接写入每位参与者的个人上下文；压缩失败时改为写入完整原文。群聊阶段不额外提取长期记忆，之后只随该人物原有的个人上下文压缩与长期记忆流程自然处理。

聊天窗支持多个并行页签，切换或关闭窗口不丢记录；后台完成的页签会亮提示。每轮真实行动的绿色结果是聊天上下文的一部分，会持久保存，重开窗口、查看历史和导出时都能看到。

左侧“会话”标题旁的“归档”按钮会打开独立弹窗，列出当前存档隐藏的单聊、群聊和灵儿对话，包括以前隐藏的记录；大量会话可翻页浏览。点击“还原”只取消隐藏，该项立即移出归档、回到会话列表，弹窗关闭，不自动打开会话或清除未读。隐藏最后一个会话后仍保留空窗口与归档入口。隐藏不删除聊天、人设、记忆或群成员，和“清空记录”不同；还原写盘失败时维持原状并提示。

可导出当前单聊、群聊、灵儿或全部聊天为本地 Markdown；不导出隐藏提示词、工具参数、密钥或思考草稿。按轮删除或重试只清理该轮对话及关联记忆，不回退已经发生的游戏状态。清空前应由玩家明确操作。

纪事按月展示江湖事件与同道行止，不重复展示普通对话。聊天仍可从各会话的导出入口保存；人物页原记录入口现为“往事成书”，会把当前人物相关的单聊、参与群聊和长期记忆整理成可导出的小说。
